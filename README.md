## 📁 Projets réalisés

### 🚢 Site de réservation de trajets en bateau

Création d'un système permettant de réserver des trajets en bateau reliant différentes îles de Bretagne.

Le projet comprenait :

- La création de réservations
- La gestion des trajets
- La consultation des informations
- Un site web relié au système
- Une interface en HTML, CSS et JavaScript

Ce projet m'a permis d'apprendre les bases du **C#**, du développement web et de la gestion de données.

---

### 🌌 Projet Stargate

Développement d'une application destinée à une base secrète de l'univers **Stargate**.

L'application permet de :

- Créer des missions
- Consulter les informations des missions
- Afficher les différentes planètes
- Gérer les races alliées et ennemies
- Utiliser l'application en mode connecté ou déconnecté

Ce projet m'a permis de découvrir et d'utiliser les **Windows Forms avec Visual Studio**.

---

### 🃏 Remake du jeu Inscryption

Reproduction d'une partie du jeu **Inscryption** en Java, avec une interface en mode texte.

Le projet utilisait :

- Des classes normales
- Des classes abstraites
- Des interfaces
- Des énumérations
- La programmation orientée objet
- Un système de cartes et de combats

Ce projet m'a permis de renforcer mes bases en **Java** et en conception logicielle.
